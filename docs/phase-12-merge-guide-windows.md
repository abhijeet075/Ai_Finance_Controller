# Add Phase 12 to the existing repository

1. Commit Phase 11 and create a `phase-12` branch.
2. Extract the cumulative Phase 12 ZIP outside the repository.
3. Copy it with `robocopy /E`; exclude `.git`, `.env`, `.venv`, `node_modules`, caches,
   `data/raw`, `data/ground_truth`, and `data/exports`. Never use `/MIR`.
4. Review `git status --short`, including untracked files.
5. Activate `.venv` and set `$env:PYTHONPATH = ".;backend"`.
6. Back up PostgreSQL, then run:

```powershell
alembic -c backend/alembic.ini upgrade head
alembic -c backend/alembic.ini current
```

The expected head is `20260902_0005`.

7. Run:

```powershell
python -m compileall backend evaluation scripts
python -m pytest -v
ruff check backend/app/api/reconciliation.py `
  backend/app/repositories/reconciliation.py `
  backend/app/services/reconciliation.py `
  backend/app/schemas/reconciliation.py `
  backend/migrations/versions/20260902_0005_phase12_run_management.py `
  backend/tests/test_run_management.py --ignore B008
```

8. Start `uvicorn app.main:app --app-dir backend --reload` and complete the sequence in
   `docs/phase-12-manual-test.md`.
9. Stage source only. Never commit `.env`, generated data, hidden truth, machine-specific
   `evaluation/batches.json`, or exports.
10. Commit with `git commit -m "Add Phase 12 API and run management"` and push the branch.

The generator now prefixes invoice numbers and settlement references with the dataset seed. Recreate
Phase 11 synthetic datasets before rerunning a matrix that was generated by an earlier package.
